# KeyLogger – Cybersecurity Course Project

A proof-of-concept developed as part of a cybersecurity course to explore how applications exhibiting malware-like behaviour operate and how existing antivirus solutions detect and respond to them.

The project demonstrates a Python-based client-server architecture with capabilities such as keyboard event monitoring, screenshot and webcam capture, remote command execution, and Windows startup persistence through registry interactions.

### Technologies Used
- **Python**
- **Socket Programming (TCP)**
- **OpenCV**
- **pyscreenshot**
- **keyboard**
- **Windows Registry (winreg)**
- **python-dotenv**

### Project Structure
- `client.py` – Client-side implementation.
- `server.py` – Server-side command interface.

**Project Type:** Academic Cybersecurity Proof of Concept.

*Developed for educational purposes and controlled security experimentation only. Not intended for unauthorized monitoring or deployment.*
